# 05 Client Success

From first "yes" to long-term partnership. Systems for onboarding clients smoothly, keeping them informed, and turning one project into recurring revenue.

## Subfolders

### Onboarding
- **Welcome Kit** — Welcome message templates, what-to-expect docs, process overview
- **Questionnaires** — Brand discovery questionnaires, project brief templates
- **Checklists** — Onboarding step-by-step checklists for each service type

### Communication Templates
- Project kickoff messages (WhatsApp + Email)
- Milestone update templates
- Revision request handling templates
- Project completion and handoff messages

### Project Updates
- Weekly/biweekly client update templates
- Progress report formats
- Deliverable presentation frameworks

### Feedback & Surveys
- Post-project satisfaction surveys
- Mid-project check-in templates
- Net Promoter Score tracking

### Upsell & Retention
- Service upsell playbooks (e.g., brand identity → web design)
- Retainer proposals for ongoing work
- Re-engagement templates for past clients
- Referral request templates
